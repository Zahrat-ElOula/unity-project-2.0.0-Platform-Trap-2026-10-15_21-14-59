# Platform Trap

A Unity-based project focused on a prototype / interactive environment experience, combining imported 3D assets, custom editor tooling, and project configuration for a platform-oriented concept.

This repository contains the Unity project files, asset packs, package integrations, and supporting configuration needed to open and work on the project locally.

## Project Overview

Platform Trap is a Unity project designed around exploration, environment building, and interactive scene composition. The repository includes:

- Unity assets and scenes
- Imported 3D environment packs
- Custom editor scripts
- Addressable asset configuration
- External package integration
- Project and build settings

The project uses a mix of C# scripts, ShaderLab materials, and Unity asset data, which aligns with a typical game-development or interactive visualization workflow.

## Repository Structure

- `Assets/` – Primary Unity project content, including models, materials, scenes, and scripts
- `ProjectSettings/` – Unity project configuration files
- `Packages/` – Unity package definitions and package dependencies
- `Locus/` – Additional project-related tooling or package support
- `LevelExports/` – Level/export assets or generated scene content
- `MarkdownRsc/` – Documentation/support resources
- `MarkdownTemplate.md` – Template for project documentation
- `CHANGELOG.md` – Project change history
- `.gitignore` / `.gitattributes` / `.vsconfig` – Git and Unity workspace metadata
